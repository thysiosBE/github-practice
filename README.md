# GitHub Practice

A sandbox repo for learning Git and GitHub. Nothing here matters, so break things freely.

## Lessons

1. **Commit** – edit `notes.md`, then `git add notes.md` and `git commit -m "My first change"`.
2. **History** – run `git log --oneline` to see every commit.
3. **Branch** – `git switch -c my-feature`, make a change, commit it.
4. **Merge** – `git switch main` then `git merge my-feature`.
5. **Push** – once connected to GitHub: `git push -u origin main`.
6. **Pull request** – push a branch and open a PR on github.com to compare it with `main`.
